# THEORY-v0.3 — 闭环定序：策略驻留引擎，轨迹涌现于回路

> **本文修订 v0.2 理论的一条根因错误**，其余定理全部继承。定位诚实：这是**控制架构归位**
> （把预推导的对象从轨迹换成策略），不是新数学；被控对象（大模型）的参数由真实会话转录
> 拟合（fit-plant 脚本，数字见 §5 表与 docs/FIT-plant.md），非引用文献——凡引用标准理论处
> 给真实出处（LQR: Kalman 1960；receding horizon MPC: Michalakopoulos/Lee & Rawlings 2003；
> 安全滤波/屏障函数: Ames et al. 2019——**正式引用前按先审校纪律复核**）。

## 0. 分叉点：预推导了什么

v0.2 的第一定律「在线只执行预推导策略」被它自己的实现背叛了：

- **freeze 冻结的是一条轨迹**——全部小类排序 + vChain 块级档链被当作合同；
- 于是偏离=违约，代价是仪式（rollback 自首、定理6 签名拒、每步重发全计划防跑偏）；
- 本会话 re-linearize 审计史 6 条，条条都是**正常的反馈在架构里被迫伪装成犯罪记录**
  （#11"目验移交真跑组"=测量修正计划，控制论里的常规动作，这里走了自首流程）。

**LQR 没有轨迹**：K 由 (Q,R) 经 Riccati 一次算出并**物化存储**，在线每步 u=−Kx 乘的是
**实测状态**。规划=策略（状态→动作的映射）+权重，**不是序列**。MPC 同理更进一步：
滚动时域每步重解、只执行第一拍、下拍用实测状态再解——**先解的是反馈增益的作用范围，
约束和终值才是合同**（终端代价保证递归可行性与稳定性，不是预排的序列）。

> **修正定理（定理 7 · 策略/轨迹分离）**：契约只绑定**权重（代价函数）、不变式、约束**；
> 下一步动作必须由**当前实测状态**实时运算。把轨迹写进合同=定理 7 违例。
> v0.2 的病名：把「预推导策略」实现成了「预推导轨道」。

## 1. 被控对象模型（大模型作为 plant/controller 双重身份）

本架构的诚实前提：被控对象不是线性时不变系统，是**带漂移、随机、内部状态不可测的
语言模型**。三个可拟合的观测事实（§5 数字）：

1. **内部状态不可观测**：模型的"记忆"随 compaction 有损、随上下文窗口滑出——transcript
   之外唯一可信的状态表面是**盘档**（引擎写入、非模型书写）。这推出架构决策：状态机的
   状态必须驻留盘档/引擎，**不得以"模型还记得"为任何正确性前提**。
2. **幻觉=测量噪声，非故障**：predictions 与实际的不吻合（discrepancies）、invalidated
   步、恢复性重读，都是该 plant 的噪声特性。对噪声系统的正确处理是反馈校正，
   不是要求开环完美预测——**给模型"每步必须预先全对"的合同，是在向噪声要确定性，
   这是 v0.2 成本恐怖的数学本质**。
3. **勤勉度衰减**（THEORY.md §4 既有观测）：长轨迹尾部验证投入下降。对时变增益的对象，
   定常开环必然失配；闭环自适应（每步重新聚焦当下块）天然免疫——**这是闭环的
   质量论据，不只是成本论据**。

## 2. 双时标架构（慢环定权，快环定序）

**慢环（合同层，用户拍板，全程驻留上下文）**：
- cost_set：Q_N 断言（severity+source）、nonGoals（确认制）、假设——**唯一不变式**；
- 大类结构（组级：title/spec/accept/verify）——权重形状；
- catastrophic 断言=**状态空间硬约束**（安全滤波：不可逆动作类永不过闸，与收益无关，
  不参与任何加权权衡——屏障函数语义，非惩罚项语义）。

**快环（执行层，每步实时运算，不进合同）**：
- **Propose**：引擎把（当前残差读数 + Q_N + 已闭集）注入为最小状态面；模型提议
  "此刻 cost-to-go 降最多的一步"——按**剩余代价距离**排序而非本步舒适度（反贪心：
  值函数=终端断言集，cost-to-go 是其在有限档下的可测代理）；
- **Declare-1**：单步一行契约（预测值+来源+≥2 通道），不再手抄组内同构件
  （beforeBand 链、law、measure 模板由引擎 merge 物化后过闸——**args=差分，闸=全量**）；
- **Do**：执行；
- **Converge-1**：ΔV 实测 vs 上一实测（异源复算、双通道，一寸不让）；不吻合=数据
  →直接进下一次 Propose（**不再有"自首仪式"**：重规划是快环的常规输出）；
- 红队/对抗审只保留在 catastrophic/major 断言所辖动作上，且审方=**引擎自派 fresh
  子代理直读盘档**（另头不另轮：全新上下文=真冷眼，且不占主会话窗口）。

**稳定性论证（启发式，诚实标注）**：ΔV 沿闭步严格降 + 终端档可达（末块 at 语义保留于
终值定义）+ 步数/预算封顶 → 有限步收敛。Lyapunov 论证的对象从"计划兑现度"换成
"代价距离"——后者才是控制该管的。

## 3. 自由的抵押物（四道闸，一条不删）

实时定序的自由度**完全由反馈的可信度赎回**，砍掉测量端=退回 v0.2 式重合同：

| 闸 | v0.2 形态 | v0.3 形态 |
|---|---|---|
| 定理4 无源=无效 | 断言/预测逐条 | 不变（Declare-1 的预测仍需来源） |
| 定理5 双通道异源 | ≥2 标识两两不同 | 不变（Converge-1 核心） |
| 定理6 反漂移 | 全局模型签名拒 | **局部化**：同一动作连败两次，换模型不换愿望 |
| 终值归零 | terminal_check | 不变（Q_N 闭合链核对） |
| 新增·无测量不放权 | — | 通道凑不齐≥2 的动作**自动按重流程**（fast loop 的准入条件，非可选） |

## 4. 成本模型（这是可证伪的预测，不是愿景）

设 P=计划记账驻留（v0.2：每步随全计划/档链/块契约线性增长，往返重发 → **O(n²) 累积**）；
v0.3 每步驻留=慢环合同（常数）+ 当前残差（常数）+ 本步差分契约（常数）→ **O(n) 累积**。
分项基线（v0.2 实测，fit-plant.mjs 两真实会话转录，见 docs/FIT-plant.md）：

| 参数 | P 场纯 v0.2（3 块小任务） | 主会话（14 块大任务） | 增长形态 |
|---|---|---|---|
| 每块协议往返 | 5.0 | 4.1 | 近线性 |
| 每块契约书写 | 6.4KB | 3.9KB | —（块大小混因） |
| 每块注入+steer | 3.9KB | 5.5KB | 超线性（计划驻留↑） |
| read 回执（失忆重读主证） | **40KB** | **445KB** | **11×/块数4.7×→超线性** |
| compaction 次数 | **0** | **152** | **阈值效应：计划记账撑窗后引爆** |
| 墙钟 | 21min（7min/块） | 1716min* | *含 GitHub 分诊与子代理等待，污染，A/B 须同任务重测 |

平方项机制：往返数 × 每轮驻留（含全计划簿记）= 累积上下文；compaction 0→152 是该积
越过窗口容量的直接读数。**v0.3 目标（可证伪）**：每块往返 ≤3、每块协议字节（书写+注入）
≤1.5KB、14 块规模会话 compaction ≤30、恢复性 read ≤100KB——数字由本表推得，A/B 不吻合
则本理论错，回改理论。

## 5. 拟合与 A/B 协议（数字见 FIT-plant.md，协议见 BENCH-ab.md）

- **拟合样本**：v0.1→v0.2 主会话（14 块）+ P 场纯 v0.2 会话（3 块）全转录解帧统计；
- **A/B 设计**：同一新任务（与两版历史任务无重合、5-10 块规模），v0.2 全量流程与 v0.3
  双时标流程各跑一遍（v0.3 由本次改造交付）；
- **三指标**：质量=终检归零+discrepancy 率+红队 reject 率+引入 bug 数（回归+真跑）；
  时间=墙钟+步数；成本=协议字节/上下文累积（fit 脚本同器测两版）；
- **预言家纪律**：v0.3 的 A/B 结果数字**由 §4 成本模型预先算出**（不吻合=理论错，
  回改理论——不允许回改数字）。
