## 3. 来源与边界

- 数字来源：DATA.md（三会话指标表+懈怠强度表）；会话 ID 于列内标注。
- 口径：`读图/小类`=read_image 事件按小类段平均；`工具/小类`=tool/call 按段平均。
- 边界：三会话**任务细节不同**（花/便利店/街区），"同型"指同为 3D 视觉场景类——对比是
  **行为模式**对比（验证勤勉度/完成模式），非效果评分对比。
- 复算：scripts/measure.mjs（下小类交付）——对任一会话可复算出该行的数字。
